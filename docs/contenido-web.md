# SECCIÓN 02 — PROBLEMA

Eyebrow:

ANTES DEL CÓDIGO

Título:

El problema no es hacer una web. Es decidir bien qué web hacer.

Texto:

Empezar directamente por el diseño o el framework parece más rápido. Hasta que llega el primer cambio y hay que rehacerlo todo.

## SIN MÉTODO

Título:

Primero diseñamos. Después pensamos.

Puntos:

- Diseño antes del contenido
- Framework elegido por moda
- CMS aunque nadie vaya a usarlo
- Assets elegidos para rellenar
- Estilos inconsistentes
- Deploy al terminar
- Cambios sin un límite claro

## CON FÓRMULA

Título:

Primero decidimos. Después construimos.

Puntos:

- Necesidad real
- Arquitectura justificada
- Contenido antes de los assets
- Sistema visual antes del código
- Preview desde el principio
- Revisiones controladas
- QA antes de entregar

# SECCIÓN 08 — CALIDAD

Eyebrow:

DISEÑO ≠ DECORACIÓN

Título:

Bonita no significa pesada.

Texto:

Una animación que empeora la experiencia no mejora el diseño.


## RENDIMIENTO

Título:

Rápida donde importa.

Puntos:

- Assets optimizados
- JavaScript mínimo
- Carga diferida
- Layout estable

Indicador:

LCP objetivo < 2.5 s


## ACCESIBILIDAD

Título:

Diseñada para utilizarse.

Puntos:

- Contraste AA
- Navegación por teclado
- Focus visible
- Reduced motion
- HTML semántico


## SEO

Título:

Preparada para encontrarse.

Puntos:

- Metadatos
- Contenido estructurado
- Sitemap
- Canonical
- SEO técnico


## MANTENIMIENTO

Título:

Tan compleja como necesita ser. No más.

Puntos:

- Arquitectura simple
- Datos separados de UI
- Código documentado
- Dependencias controladas
